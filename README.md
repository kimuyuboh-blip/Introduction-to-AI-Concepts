## Introduction
Artificial Intelligence (AI)- Creating computer systems that can think, learn and make decisions in ways that feel human.
AI is about creating systems that can learn from data and make intelligent decisions just like humans but faster and at a much larger scale.

It's advanced math, massive data and smart algorithms working together to make the world intelligent.

## Machine Learning (ML)
Machine learning (ML) is a subset of (AI) that enables systems to automatically learn, improve, and make predictions from data without being explicitly 
programmed for every specific task. 
Instead of rigid instructions, algorithms analyze large datasets to identify patterns, building models that refine their accuracy over time through experience.

The process involves feeding training data into an algorithm to create a model, which is then validated with testing data to ensure accuracy. 

Machine learning allows computers to behave like humans by learning from past experiences(DATA) to make informed decisions.
